# Healthcare Symptom Triage

## About
A web application that predicts 
symptom severity and recommends:
- Home remedies for minor symptoms
- Nearby hospital for major symptoms

## Tools Used
- Python
- Random Forest (Scikit-learn)
- Streamlit
- Kaggle Dataset

## How It Works
1. User enters symptom
2. Model predicts severity
3. Minor → Home remedy shown
4. Major → Nearby hospital directed
